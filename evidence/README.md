# Execution evidence (Deliverable 06)

Generated by `python scripts/run_sandbox_demo.py`, which replays the full scenario through the real REST API on a fresh sandbox database. All data is synthetic; the financing provider is a deterministic sandbox and no real money moves.

| File | What it proves |
|---|---|
| `execution_log.jsonl` | Raw JSON request/response for every API call (logins, ingestion, scoring, forecast, agent run, owner approval, provider response, Q&A, negative tests). Tokens are redacted. |
| `summary.json` | Key outcomes: score, funding gap, recommended financing, alternatives, agent steps, provider reference. |
| `security_tests.json` | 12 negative tests (RBAC denials, tenant isolation, XXE, size limit, double approval, brute-force lockout, audit-chain tamper detection) with expected vs actual results. |
| `audit_chain.json` | Full hash-chained audit trail with `prev_hash`/`entry_hash` per entry, plus the verification result. |
| `db_dump_raw.json` | Database output dump: row counts and sample rows exactly as stored, showing AES-256-GCM envelopes instead of plaintext amounts and names. |
| `simulated_transactions_decrypted.csv` | Simulated bank transaction records after decryption (what the AI reads). |
| `simulated_invoices_decrypted.csv` | Simulated e-invoice records after decryption, including the status change to `financed` after approval. |
| `financing_applications_decrypted.json` | The agent-drafted application, its owner approval and the sandbox provider response. |

The demo video (Deliverable 03) shows the same flow live in the dashboard.
